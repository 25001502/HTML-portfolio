# 🌐 Personal Portfolio Website

A responsive personal portfolio website built using **HTML** and **CSS** to showcase my academic background, skills, interests, projects, and contact information.

## 🚀 Live Preview
You can preview the portfolio here:  
**[nengovhela.me](https://nengovhela.me)** for the ultimate version of the portfolio

## 📂 GitHub Repository
This repository contains the full source code for my personal portfolio website.

## 📖 Project Overview
This project was developed as part of an **HCI assignment**.  
The objective was to design and develop a **responsive**, **user-friendly**, and visually appealing personal portfolio website while applying good interface design practices learned in class.

## 🧩 Sections Included
The portfolio includes the following sections:

### 🏠 Homepage / Introduction
- Welcome message / personal tagline
- Short bio or introduction
- A personal photo

### 👨‍🎓 About Me
- Academic background
- Skills and tools I am familiar with
- Career / academic goals

### 💼 Projects
- At least two projects
- Each project includes a title, description, and tools used

### 📞 Contact
- Email address
- Links to GitHub, LinkedIn, or other relevant profiles

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript** *(optional, if included)*
